# START HERE — Aawaz on Monad (Blitz / Testnet)

## Wallet: MetaMask (not Phantom)

1. Install MetaMask: https://metamask.io
2. Connect in the app — it will add **Monad Testnet** automatically  
   Or add manually (see `MONAD_BLITZ_SETUP.md`)
3. Get free MON: https://faucet.monad.xyz

---

## Run in 3 steps

```bash
npm install
cp env.example .env.local   # add GROQ_API_KEY
npm run dev
```

Open http://localhost:3000

---

## Try it

1. Click **Connect MetaMask**
2. Open Transaction Hub
3. Say or type: `Send 0.01 MON to 0x...`
4. Confirm → Sign in MetaMask → Done
